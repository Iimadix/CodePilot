**CodePilot** — это веб-сервис, созданный для того, чтобы помочь разработчикам подготовиться к собеседованиям.

## Технологический стек
- **Backend:** PHP, MySQL
- **Frontend:** JavaScript, HTML5, CSS3
- **Архитектура:** Клиент-серверная с использованием AJAX (Fetch API)

## Основные функции
*   **Тренажер собеседований:** Пошаговая настройка (Направление -> Язык -> Стаж) и тест из 10 случайных вопросов
*   **База знаний:** Каталог из 500+ вопросов с разбором ответов, разделенный на темы и уровни сложности
*   **Личный кабинет:** Профиль пользователя с детальной статистикой
*   **Безопасность:** Хеширование паролей, фильтрация контента

## Структура проекта
- /js — клиентские скрипты и логика тренажера
- /php — серверная логика, обработка авторизации и запросы к БД
- /images — графические ресурсы и иконки
- /components — переиспользуемые шаблоны (header, footer)
- /database — дамп базы данных

## Запуск проекта
Для работы проекта вам понадобится локальный сервер, например XAMPP (или другие).
*Шаг 1: Подготовка файлов*
1. Склонируйте репозиторий или скачайте архив с проектом.
2. Перенесите папку с проектом в рабочую директорию вашего локального сервера:
3. Для XAMPP: ваш_диск:/xampp/htdocs/codepilot
- Для OpenServer: путь_к_программе/domains/codepilot
*Шаг 2: Импорт базы данных*
1. Откройте панель управления сервером и запустите модули Apache и MySQL.
2. Перейдите в браузере по адресу http://localhost/phpmyadmin.
3. Создайте новую базу данных с названием codepilot (кодировка utf8mb4_general_ci).
4. Выберите созданную базу, нажмите вкладку «Импорт» (Import).
5. Нажмите «Выберите файл» и выберите файл database/codepilot.sql из папки проекта.
6. Нажмите кнопку «Вперед» внизу страницы.
*Шаг 3: Настройка подключения*
1. Откройте файл php/config/connect.php в текстовом редакторе.
2. Проверьте настройки подключения к базе, по умолчанию они должны выглядеть так:
```
PHP
$host = "localhost";
$user = "root";      // стандартный пользователь
$password = "";      // по умолчанию в XAMPP/OpenServer пароль пустой
$database = "codepilot";
```
3. Сохраните файл.
Шаг 4: Запуск сайта
1. Откройте ваш браузер.
2. Введите в адресную строку: http://localhost/codepilot/index.php.
3. Готово! Вы должны увидеть главную страницу платформы.
