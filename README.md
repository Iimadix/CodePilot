**CodePilot** — это веб-сервис, созданный для того, чтобы помочь разработчикам подготовиться к собеседованиям.

## Технологический стек
- **Backend:** PHP, MySQL
- **Frontend:** JavaScript, HTML5, CSS3
- **Архитектура:** Клиент-серверная с использованием AJAX (Fetch API)

## Основные функции
*   **Тренажер собеседований:** Пошаговая настройка (Направление -> Язык -> Стаж) и тест из 10 случайных вопросов
*   **Система Snapshot:** Результаты тестов сохраняются в формате JSON, что гарантирует неизменность истории ответов
*   **База знаний:** Каталог из 500+ вопросов с разбором ответов, разделенный на темы и уровни сложности
*   **Личный кабинет:** Профиль пользователя с детальной статистикой
*   **Безопасность:** Хеширование паролей, фильтрация контента

## Структура проекта
- /js — клиентские скрипты и логика тренажера
- /php — серверная логика, обработка авторизации и запросы к БД
- /images — графические ресурсы и иконки
- /components — переиспользуемые шаблоны (header, footer)
- /database — дамп базы данных
